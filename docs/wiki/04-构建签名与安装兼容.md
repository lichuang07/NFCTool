# 构建、签名与安装兼容

## 常用命令
```bash
cd F:/Work/App/NFCTool
JAVA_HOME="C:/Users/lichuang/.jdks/jbr-17.0.14" ./gradlew assembleDebug --no-configuration-cache
bash tools/build_release.sh      # clean 构建 + 四项校验 + 收集到 dist/
bash tools/diagnose_install.sh    # 安装失败时拿真实错误码
```

⚠️ **体积必须 clean 构建后测**：实测同一份代码 clean 构建 5.10MB、增量构建 9.58MB，
增量产物不可用于判断安装兼容性。

## 构建约束（踩过的坑，勿回退）
1. 全局 Gradle 代理失效，项目 `gradle.properties` 用 `systemProp.http.nonProxyHosts=*` 绕开，**别删**
2. AGP 9 内置 Kotlin，**不要**应用 `org.jetbrains.kotlin.android`；
   Compose / Serialization 插件放根 `buildscript { classpath }`
3. compileSdk 37 平台目录名必须是 **`android-37.0`** 且含手写 `package.xml`（官方 zip 不含）
4. SDK 组件是手工补齐的（platform-36/37.0、build-tools 36/37、platform-tools r37）
5. `gradle/gradle-daemon-jvm.properties` 的 `toolchainVersion` **必须是 17**
   （=25 会联网下 JDK 25 并失败；症状报 "matching: {languageVersion=25}"，与 AGP/KGP 无关）
6. 本机 `java` 不在 PATH，apksigner 用
   `$JAVA_HOME/bin/java.exe -jar build-tools/37.0.0/lib/apksigner.jar`
7. XML 注释**不能**放在标签属性之间 → `processDebugMainManifest` FAILED

## APK 安装兼容（国产 ROM 高发坑）
症状：安装报 `packageInfo is null`，但 4 项校验全过。
真因通常是 **体积 > 10MB 传输被截断**（19MB 反复失败，压到 5MB 内稳定）。

规避：
1. 渐变用 PNG 位图，**禁止 `<aapt:attr>`**（会生成 `$xxx__0.xml` 内部资源，部分 ROM 解析失败）
2. R8 + 资源裁剪 + `abiFilters arm64-v8a` + `ui-tooling` 改 `debugImplementation`
3. 三签名齐开（v1 在 minSdk 24 会被跳过，属正常）
4. 排查顺序：4 项校验 → `$` 资源 → 体积

**四项校验**（`build_release.sh` 已内置）：
```
java -jar apksigner.jar verify --print-certs -v app.apk   # v2 + v3 Verifies
zipalign -c 4 app.apk                                     # Verification successful
unzip -t app.apk                                           # No errors
unzip -l app.apk | grep '$'                                # 应无输出
```

## adb 调试要点
- adb 路径：`~/AppData/Local/Android/Sdk/platform-tools/adb.exe`（**不在 PATH**）
- 抓崩溃：`adb logcat -b crash -d`（crash 缓冲混了别的应用的历史崩溃，要按时间戳 + 包名过滤）
- ⚠️ Git Bash 会做 MSYS 路径转换，`adb shell pm install /data/local/tmp/x.apk`
  会被转成 `D:/Program Files/...` → 必须 `export MSYS_NO_PATHCONV=1`
- 小米 `adb install` 报 `INSTALL_FAILED_USER_RESTRICTED` →
  开发者选项里开「USB 调试（安全设置）」；或 push 到 `/sdcard/Download/` 用文件管理器装
- 小米限制 `input tap`（需 INJECT_EVENTS），模拟点击不可用，只能手动点
