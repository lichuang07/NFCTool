## 已修的两个 UI 缺陷
- **底栏在详情页一直没隐藏**：判断写成 `currentRoute != "write_detail/{entryId}"`，
  右侧是带占位符的**模板**，左侧是**实际**路由 `"write_detail/uri"`，永远不相等。
  改成前缀匹配 `startsWith("write_detail/")`
- **返回手势播放"回桌面"缩放动画**：Android 15+ 预测式返回，
  未注册 `BackHandler` 时系统会缩放整个 Activity，且详情页返回直接退出应用
