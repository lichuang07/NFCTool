# 需求 Backlog 与路线图

## 最优先
**真机 NFC 读写逐项验证** —— 需要实体标签与支持 NFC 的设备。
当前代码已通过编译、静态检查与 222 个单测，但**未经真机实测**，
合入生产前必须跑一遍：NDEF 读写 / MIFARE / Ultralight / ISO15693 / APDU / HCE / 复制标签。

## 尚未实现
| 项 | 说明 |
|---|---|
| DESFire EV2 密钥管理 | KeyManager 相关指令未封装，当前只有版本 / 文件列表 / 文件读写 |
| 标签导入 | 导出的 JSON 目前只能查看，无法反写回标签 |
| HCE 可配置卡片 | 响应数据写死在 `HceProfile`，未提供 UI 编辑 |
| 后台标签历史去重 | 后台扫描事件未走防抖逻辑 |
| geo: / 蓝牙 OOB 真机验证 | 尤其 `geo:` 能否唤起地图、目标手机是否注册了 OOB MIME |

## 功能候选（按价值 ÷ 成本排序）
| # | 功能 | 价值 | 成本 | 说明 |
|---|---|---|---|---|
| 1 | 我的模板 / 收藏夹 | 高 | 中 | 常用写入内容存下来一键再写。复制页的快照已是整条消息字节，持久化后天然是模板数据源 |
| 2 | HEX 页面编辑器 | 高 | 中 | 按页浏览 + 改单字节。控制台已有原始指令通道，缺这层 UI |
| 3 | 标签锁定 / 密码管理 | 中高 | 中 | `Ndef.makeReadOnly()` 已接在复制页；可独立成页并补 NTAG PWD/PACK |
| 4 | 历史记录搜索与批量导出 | 中 | 低 | 现在只能一张张导出 |
| 5 | NDEF 记录编辑器 | 高 | 中高 | 手工增删记录、调序、改单条内容 |
| 6 | 标签容量体检 | 中 | 低 | 扫描全卡，报告可用容量、坏块、锁定位 |
| 7 | 批量连续写入 | 中 | 低 | 复制页已有「再复制一张」，可升级为设定张数自动连写 |
| 8 | NDEF → 二维码分享 | 中 | 低 | 项目已自带 QR 编码器 |
