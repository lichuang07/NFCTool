# NFCTool 项目概览

## 定位
Android NFC 标签读写工具箱。包名 `com.nfctool.app`，工程根目录 `F:/Work/App/NFCTool/`。
目标是把手机 NFC 能做的事全部做成可见、可操作的界面，覆盖读取、写入、克隆、调试、卡模拟。

## 页面结构
底部 5 个常驻 tab + 2 个全屏任务页：

| 路由 | 页面 | 职责 |
|---|---|---|
| `read` | 读取页 | 扫描标签、型号识别、NDEF 解析、块级数据、导出 |
| `write` | 写入页 | 18 种写入类型的目录 |
| `console` | 控制台页 | 原始指令 / APDU 透传、SELECT AID、通信日志 |
| `history` | 历史页 | 最近 200 条扫描记录 |
| `settings` | 设置页 | 主题、强调色、语言、HCE 面板、设备信息 |
| `write_detail/{id}` | 写入详情页 | 各类型表单（全屏，隐藏底栏） |
| `clone` | 复制标签页 | 读源卡 → 写目标卡（全屏，隐藏底栏） |

## 核心能力
- **读取**：卡片型号自动识别（NTAG21x / Ultralight / Classic / DESFire / ISO15693 / FeliCa / 银行卡 / 门禁卡）、NDEF 四态区分、块级 dump
- **NDEF 细分类型**：在 TNF 之上做应用级二次归类（Wi-Fi / 名片 / 应用记录 / 移交 / 地理位置 / 蓝牙 OOB / AID）
- **写入**：18 项 / 6 分组，写入任务挂起等标签，写完回读校验
- **复制标签**：整条 NDEF 消息字节快照，可连续复制多张
- **整卡备份**：Classic（按扇区，需密钥）与 NTAG / Ultralight（按页，无需密钥）都能存成 JSON 再写回同型号卡；不碰密钥尾块、不写 UID
- **模板收藏夹**：常用内容存下来，点一下自动填好写入表单（复用分享预填那条通道）
- **接收分享**：地图 / 浏览器 / 联系人 / 图片分享进来自动预填写入表单
- **HCE**：手机扮演卡片，AID 声明式注册
- **后台读卡**：connectedDevice 前台服务 + 动态 receiver
- **国际化**：简体中文（默认）+ English
