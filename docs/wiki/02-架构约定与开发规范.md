# 架构约定与开发规范

以下约定均为踩坑后确立，**修改时不要回退**。

## 写入页两级结构
```
write  (目录页，WriteEntry.kt 18 项/6 分组是唯一目录源)
   └── write_detail/{entryId}  (详情页表单)
```
新增一种写入类型 = 目录加一条 + 实现一个表单，目录页布局不用动。

## Codec 必须拆成纯字节
Android 的 `NdefRecord` 在 JUnit 里不可用，所以 payload 组装一律拆成
`encodePayload` / `decodePayload` 两个纯函数，`NdefRecord` 只做薄壳。
不这么做就写不了单测，等价于"没测过"。

## NDEF 细分类型层
NDEF 规范只有 8 种 TNF，业务语义压缩在 type 字段里，只按 TNF 归类会让
Wi-Fi 卡和 JPEG 卡看起来完全一样。因此在 TNF 之上加了 `NdefKind` 二次归类：
- 新增流程：`NdefKind` 加枚举 → `NdefTypeRegistry.classify` 加分支 → 写 Codec → `details` 接入

## 写入结果可信性（最关键的一条）
`launchWrite` 的 block 签名固定为 `suspend (TagSession) -> Result<Any?>`，
内部用 `getOrThrow()` 把 `Result.failure` 转成异常。
**NDEF 写完必须回读逐字节校验**（`NdefVerify.sameRecords`）——
部分机型在标签离开感应范围时 `writeNdefMessage` 不抛异常却没写进去。

## 写入任务挂起等待标签
`launchWrite` 只记录 `PendingWrite` 并弹全局「请靠近标签」提示，
真正执行在 `onTagDiscovered`。提示挂在 `NfctoolAppRoot` 而非页面内，
因为写入任务可能跨页面存活。点击写入时**主动清空 1.5 秒同 UID 防抖**，
否则"刚扫过同一张卡再点写入"会被吞掉。

## 其他硬约束
- **同一 Tag 同时只能连一个 `TagTechnology`**，探测页数后必须 close 再读 NDEF
- **Reader Mode** 在 onStart/onResume 启用，读卡成功后**不要立刻关闭**（系统 NFC 应用会抢前台）
- **后台读卡**：`enableReaderMode` 宿主必须是 Activity（Service 不行）→ 用 `connectedDevice` 前台服务 + 动态注册 receiver
- **HCE**：AID 只能通过 `res/xml/apdu_service.xml` 声明式注册，`ApduServiceInfo` 是隐藏 API
- **国际化**：枚举展示字段一律 `@StringRes`；历史记录 / 快照存**枚举名**不存中文串

## 返回手势（Android 15+ 必读）
targetSdk ≥ 35 时 `android:enableOnBackInvokedCallback` **默认为 true**。
只要应用没注册 `OnBackPressedCallback`，系统就把每次返回当成"回桌面"，
播放窗口缩小 + 半透明的 back-to-home 动画；更糟的是此时按返回键会直接
`finish()` **退出整个应用**。
→ manifest 显式关掉该属性 + `NfctoolAppRoot` 注册 `BackHandler`
（订阅 `currentBackStackEntryFlow` 判定，根页面不拦截）。

## 复制标签
- `core/nfc/ndef/NdefMessageCodec.kt`：NDEF 消息层纯字节编解码，
  避开已废弃的 `NdefMessage.toByteArray()`
- `core/nfc/TagCloner.kt`：`CloneSource` 快照 + `capture()` / `write(lock)`
- 复制**整条消息**而非逐记录，以保留 ID / MB/ME / SR 等元信息
- 入口在写入页顶部与读取页读完卡片后（**不进底部导航**，任务型页面）
- 快照存枚举名，写完不清空，可连续复制多张

## Compose 踩坑（组合期不报错、运行才崩）
- **`Brush.*Gradient` 至少要 2 个颜色**：颜色数校验在**绘制阶段**
  （`validateColorStops`），只给 1 个颜色编译 / lint / 单测全过，
  真机渲染到就抛 `IllegalArgumentException`（表现为进页面直接闪退）。
- **XML 注释不能放在标签属性之间**，`<application android:name="..." <!--注释--> >` 是非法的，
  会导致 `processDebugMainManifest` FAILED。
- **`joinToString { }` 的 lambda 不是 @Composable 上下文**，里面不能调 `stringResource`，
  要改成显式 `for` 循环收集。
- `Icons.Rounded.ArrowBack` 已废弃 → 用 `Icons.AutoMirrored.Rounded.ArrowBack`。
