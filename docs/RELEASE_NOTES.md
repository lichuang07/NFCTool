## NFCTool v1.0.1

Android NFC 标签读写工具箱（`com.nfctool.app`），Jetpack Compose 单 Activity 实现。

### 下载哪个

| 文件 | 体积 | 说明 |
|---|---|---|
| `NFCTool-v1.0.1-arm64.apk` | 5.0 MB | **日常用这个**。R8 混淆 + 资源裁剪 + 仅 arm64-v8a |
| `NFCTool-v1.0.1-noshrink-compare.apk` | 20.3 MB | 仅裁 ABI、不混淆。**只在主推版装不上时**用来对比定位 |

要求 Android 7.0（API 24）以上、设备带 NFC。装过旧版请先卸载：`adb uninstall com.nfctool.app`。

### 本版功能

- **读取**：卡片型号自动识别（NTAG21x / Ultralight / Classic / DESFire / ISO 15693 / FeliCa / 银行卡 / 门禁卡）、NDEF 解析与细分类型归类、块级 dump、导出 JSON
- **写入**：18 种类型分 6 组；写入任务挂起等标签靠近，写完**回读逐字节校验**
- **复制标签**：复制整条 NDEF 消息字节（保留 ID / MB·ME / SR 元信息），可连续复制多张
- **整卡备份**：Classic（按扇区，需密钥）与 NTAG / Ultralight（按页，无需密钥）存成 JSON，再写回同型号卡
- **MIFARE 密钥本**：保存常用密钥，备份时依次尝试
- **模板收藏夹**：常用内容存下来，点一下自动填好写入表单
- **控制台**：原始指令 / APDU 透传、SELECT AID、通信日志
- **HCE 卡模拟**、**后台读卡**、**接收系统分享自动预填**
- 中英双语（约 890 条 × 2）

### 安全边界

**不能用来复制门禁卡。** 门禁读头大多只认 UID，而 UID 出厂锁定、不可写；
手机钱包能模拟是因为走厂商私有通道 + 系统签名权限，第三方 App 拿不到。
整卡备份**不碰密钥尾块、不写 UID**，恢复出来的卡仍是目标卡自己的 UID。

本工具只对自己拥有的卡片做读写与调试，不提供任何密钥破解 / 绕过门禁的能力。
